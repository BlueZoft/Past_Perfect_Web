# Web front-end of an online marketplace application

This is the frontend of an online marketplace web application I built as a client project. The full codebase is not available here for obvious reasons, but I saved a snapshot of the repository halfway through to showcase some of the technologies used.

The Packages and technologies used are as follows.

Core packages:
  - React DOM with JavaScript as the programming language - Web rendering and routering
  - axios - Handle async functions
  - stripe - Handle payments

Note: Frontend data is only validated and not encrypted before transit as this is a snapshot of the repository before testing and security implementations that are required for a live environment.
